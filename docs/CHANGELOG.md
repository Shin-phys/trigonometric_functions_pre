# 改訂履歴

形式：`## [バージョン] - 日付` の下に「追加／変更／修正」を書く。
仕様書（SPEC.md）の版と、アプリの版（package.json の version）は別に管理する。

## [0.4.0] - 2026-10-01

仕様書 v3.2。

### 追加
- ゲストモード：名前を入力せずにすぐ遊べる（トップの「ゲストですぐ遊ぶ」、参加画面の「ゲストで遊ぶ」、`/play/?guest=1`）
  - 記録は送信しない。端末内の自己ベストは生徒本人の記録と分けて保存（到達判定に混ざらない）
  - リザルトで到達判定を表示しない

## [0.3.0] - 2026-09-30

仕様書 v3.1。

### 削除
- Stage 0（角度認識）を廃止。ウォームアップは成分選択（Stage 1〜3）と発展モードに絞る
  （関連する出題ロジック `generators/angle.ts`、選択肢・表示名も削除）

### 変更
- 斜面の図の θ は底角だけに表示し、力の分解側（mg と斜面垂直線の間）には描かない（Stage 2 も Stage 3 と同じ図に）
- ゴールの問題数を全ステージ共通の設定から、ステージごとの山札の枚数に変更（`GAME.goalCorrect` を廃止。現状はすべて 12 問）

## [0.2.0] - 2026-09-26

仕様書 v3 に基づく改訂（授業での使い方を想定した相談を反映）。

### 変更
- 選択肢を 2 択に（平面は Fsinθ / Fcosθ、斜面は mgsinθ / mgcosθ、発展は mgtanθ / mg/cosθ）。1 問の中で F と mg を混ぜない
- ボタンの並びを固定（左 sin・右 cos）。縁の色をフィードバックの 対辺＝赤／隣辺＝青 にそろえた。キー ← → / 1 2 / F J に対応
- Stage 0 を θ / 90°−θ の 2 択に（90°+θ・180°−θ の候補角を削除）
- 斜辺（力そのもの）の出題を廃止
- 60 秒の時間制 → 「12 問正解でゴール」のタイムアタック。記録はクリアタイム
- 誤答時は 1.5 秒ロック（赤青表示）→ 新しい問題へ（誤答は正解数に数えない）
- 出題を山札方式に（12 問の構成を固定し、順番・θ・反転だけランダム）
- ダッシュボード：タイム TOP5・ステージごとの到達者数・タイムの中央値（スコア・伸び率ランキングは廃止）
- Firestore の記録項目を変更（score・prevScore → clearMs・medianMs・mastered）。ルールも更新

### 追加
- 到達（自動化）判定：直近 3 回で正答率 95%以上 かつ 正解時の反応時間の中央値 1.0 秒以下
- リザルトに間違えた問題の図の一覧（正解とあなたの答え、タップで拡大）
- 「間違えた問題だけもう一度」復習モード（時間は計らず、記録しない）
- ステージ選択に自己ベストと到達バッジ

### 注意
- 端末内の履歴は形式が変わったため、v0.1 の記録は引き継がれない
- Firebase を設定済みの場合は `firebase/firestore.rules` を再デプロイする

## [0.1.0] - 2026-09-24

仕様書 v2 に基づく初版。

### 追加
- Stage 0（角度認識）：強調した角が θ / 90°−θ / 90°+θ / 180°−θ のどれかを選ぶ。θ と等しい角の出題が約半分。45° 付近は出題しない
- Stage 1〜3（成分選択）：水平・鉛直・斜面の 3 パターン、図の上下左右反転をランダム化
- 発展モード A1：3 力のつり合い（つるして水平に引く／斜面を水平に押す）で mg tanθ と mg/cosθ
- 誤答時フィードバック：対辺＝赤・隣辺＝青を 0.7 秒表示（発展モードは力の三角形も表示）
- リザルト：スコア・正答率・平均時間・前回の自分との比較・まちがえた問題
- 教員ダッシュボード：参加人数・平均正答率・平均スコア・ハイスコア TOP5・伸び TOP5・誤答率の高いパターン
- Firebase（Firestore・匿名認証）連携、未設定時はローカルモード
- PWA（manifest・Service Worker）、GitHub Pages 自動公開

### 実装上の判断（仕様書からの補足）
- 出題の強調色は黄橙にした（誤答フィードバックの「赤＝sin」と混同しないため。`config/theme.ts` で変更可）
- Stage 0 は「どの角か」ではなく「強調した角の大きさ」を 4 択で問う形にした（基本 UI の「1 箇所を強調して 4 択」と揃えるため）
- 平面パターンの力は F、斜面パターンの力は mg で描く
