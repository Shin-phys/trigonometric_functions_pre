## 1. システム概要

- **アプリ名称（仮）**：ベクトル分解タイムトライアル（Vector Breakout）
- **コンセプト**：「考えずに直感で選べる」状態を作る、高1物理基礎向け超高速ベクトル成分分解トレーニングツール
- **利用環境**：Webブラウザ（PWA対応想定／スマホ・タブレット・PCレスポンシブ）
- **バックエンド**：Firebase（Cloud Firestore）

## 2. 目的・学習仮説

- **狙い**：授業冒頭1〜3分の帯活動（ウォームアップ）として継続実施し、ベクトルの成分分解を自動化（パターン反射化）させる
- **教育仮説**：物理の思考（立式・運動予測）におけるワーキングメモリを節約するため、「図の見た目 → 成分（数式）」の変換を認知科学的に自動化させる。数学的な理論の追いつきは後追いで対応する
- **v2での追加仮説**：成分選択の反射を鍛える前段として、「どの角がθと等しいか」を見抜く回路が未定着だと、上位の反射が土台を欠いたまま積み上がる。この判別を独立した最初のステージとして切り出す
- **v3での整理**：判断を「sin か cos か」の1点に絞り、選択肢の読み取りなど課題と関係のない認知負荷を極力落とす

## 3. 基本UI・回答方式

| 項目 | 仕様詳細 |
|---|---|
| 画面構成 | 上部：問題となる図（強調表示されたベクトルまたは角）／下部：2択の選択ボタン |
| 出題方式 | 分解されたベクトル図の中で、ターゲットとなるベクトルまたは角を1本（1箇所）強調（黄橙・太線）する |
| 回答方式 | 強調対象に対応する選択肢を2択ボタンから選ぶ。**並びは固定**（左 sin・右 cos）とし、ボタンの縁を 対辺＝赤／隣辺＝青 にそろえる |
| テンポ感 | 1問あたり0.5〜1.5秒で回答できる超高速オペラント学習形式 |

## 4. 出題ロジック・グラフィック仕様

### ①-0 角度認識（Level 0）

成分選択の反射に入る前に、「θと合同な角」を見抜く回路を独立して鍛える。

- 出題：分解図の中の角を1つ強調し、その大きさが「θ」か「90°−θ」かを2択で選ばせる（並び固定：左 θ・右 90°−θ）
- 目的：錯角・同位角の見落としによる下流の誤答（sin/cos取り違え）を根本から減らす
- Stage 1（成分選択）に進む前提条件として位置づける

### ① 認知パターンのランダム化（「横＝cos」の誤認防止）

常に以下の3パターンのいずれかを生成・描画する（図の上下左右の反転もランダム）。

- **水平パターン**：水平方向となす角がθ
- **鉛直パターン**：鉛直線となす角がθ
- **斜面パターン**：斜面垂直線となす角がθ（斜面上の重力分解）

### ② 正解の判定ロジック

- θの**対辺**（向き合っている辺）を強調 → **sin** が正解
- θの**隣辺**（くっついている辺）を強調 → **cos** が正解
- 斜辺（力そのもの）は出題しない（図に力の名前が書かれているので、2択では答えが見えてしまう）

### ③ 選択肢

基本モードは **sin / cos の2択**。1つの問題の中で F と mg を混ぜない。

- 平面パターン（力 F）：**Fsinθ ／ Fcosθ**
- 斜面パターン（重力 mg）：**mgsinθ ／ mgcosθ**

tanθ を含む比率項は基本モードから完全に除外し、発展モード（**mgtanθ ／ mg/cosθ** の2択）でのみ扱う。

## 5. モード・ステージ構成

### 【基本モード】分解マスター（ウォームアップメイン）

- **Stage 0：角度認識** … θと合同な角を見抜く（θ／90°−θ）
- **Stage 1：平面分解（基本）** … 水平・鉛直な面での分解
- **Stage 2：斜面分解（実戦）** … 斜面上の重力分解（底角と物体側の両方に θ を表示）
- **Stage 3：ランダム（実力試し）** … 全パターン混合（斜面は底角の θ のみ表示）

### 【発展モード】tan との使い分け（別モードとして分離）

成分の「長さ」ではなく、2力の「比率関係」を問う問題（つるしたおもりを水平に引く力と張力、斜面の物体を水平に押す力と垂直抗力など）として独立したステージで出題する。mg/cosθ、mgtanθ 等の非直交項はここでのみ登場する。

### 出題の組み方：山札方式

1ラウンド12問の構成をステージごとに固定し（例：Stage 1 は 水平・鉛直 × sin・cos を各3問）、順番・θ・図の反転だけをランダムにする。構成を固定することで、クリアタイムを公平に比較できる。誤答で12問を使い切ったら、同じ構成の山札を新しく切って続ける。

## 6. ゲームルール・フィードバック

- **形式**：**12問正解でゴール**するタイムアタック。記録は**クリアタイム**
- **誤答時**：**1.5秒ロック**（操作不可）。その間「対辺＝赤（sin）」「隣辺＝青（cos）」をハイライトし、文字解説なしで残像記憶として正解位置を印象づける。誤答した問題は正解数に数えず、次は**新しい問題**に進む
  - 同じ問題をやり直させる方式だと、2択では残りを押せば必ず正解になり、当てずっぽうが得をする（1問あたり約1.2秒）
  - 新しい問題に進む方式なら、当てずっぽうは1問正解あたり「2回押す＋ロック1回」で約2.1秒かかり、考えて答えるより不利になる
- **到達（自動化）判定**：ゲームの記録とは別に、直近3回分のプレイをまとめて次の2条件で判定する
  - 正答率 95%以上
  - 正解時の反応時間の**中央値** 1.0秒以下（平均でなく中央値にして、よそ見などの外れ値の影響を除く）
- **評価での位置づけ**：クリアタイムは動機づけ・ランキング用。成績（知識・技能）の根拠には到達判定を使う。実施回数や伸びは「主体的に学習に取り組む態度」の直接の根拠にはしない

## 7. システム構成・画面遷移

### ① 生徒用画面（/play）

- **ルーム接続**：クラスコード（例：1A）と出席番号／ニックネームを入力
- **ゲームプレイ**：12問正解でゴールのタイムアタック
- **リザルト**：クリアタイム、前回・自己ベストとの比較、正答率、反応時間の中央値、到達判定
- **間違えた問題の一覧**：リザルトの下に、間違えた問題の図を 対辺＝赤／隣辺＝青 の色付きで並べ、「正解」と「あなたの答え」を表示する。タップで拡大。「間違えた問題だけもう一度」で同じ図を復習できる（時間は計らず、記録もしない）

### ② 教員・投影用ダッシュボード（/dashboard）

プロジェクターや電子黒板にリアルタイム投影する専用画面。

- 現在のリアルタイム参加人数
- クラス全体の平均正答率・クリアタイムの中央値（リアルタイム集計）
- 本日のタイムTOP5
- ステージごとの到達者数
- 誤答率が高かった問題パターン（授業冒頭のピンポイント解説用）

## 8. 非機能要件・開発技術スタック推奨

- **フロントエンド**：Next.js / React, Tailwind CSS
- **数式レンダリング**：KaTeX（高速・軽量描画）
- **データベース・認証**：Firebase Cloud Firestore / Anonymous Auth（匿名認証でログイン不要）
- **画面対応**：
  - スマホ（縦）：上部「図」／下部「2択ボタン（左右）」
  - タブレット・PC（横）：左側「図」／右側「2択ボタン」
  - PC のキー操作：← →、1 2、F J

| 力の記号 | 平面パターンは F、斜面パターンは mg | `generators/component.ts` |

| 発展モードの題材 | つるしたおもりを水平に引く（T, F）／なめらかな斜面の物体を水平に押す（N, F）。誤答時は力の三角形を表示 | `generators/tan.ts`、`scenes.ts` |

| バックエンド | Cloud Firestore のみ使用。`onSnapshot` でリアルタイム集計 | `lib/firebase/` |

## 変更点

### v1 → v2

| 項目 | v1 | v2 |
|---|---|---|
| 角度認識 | なし | Stage 0として新設 |
| ダミー3 | mg/cosθ・mgtanθ（非直交項） | Fsinθ（直交成分内の取り違え） |
| tan項の扱い | 基本モードのダミーに混入 | 発展モードに完全分離 |

### v2 → v3

| 項目 | v2 | v3 |
|---|---|---|
| 選択肢 | 4択（F と mg を混在） | 2択（sin / cos）。1問の中で F と mg を混ぜない |
| 斜辺の出題 | あり | なし |
| Stage 0 | θ／90°−θ／90°+θ／180°−θ | θ／90°−θ |
| ボタンの並び | シャッフル | 固定（左 sin・右 cos、縁を赤・青） |
| ゲーム形式 | 60秒の時間制・スコア | 12問正解でゴール・クリアタイム |
| 誤答時 | 一瞬のハイライト | 1.5秒ロック＋ハイライト、新しい問題へ |
| 出題の組み方 | ランダム | 山札方式（構成固定） |
| 評価 | スコア（速さ×正確さ） | ゲーム記録＝クリアタイム、成績＝到達判定（正答率＋反応時間の中央値） |
| リザルト | スコア・前回比 | ＋間違えた問題の図の一覧・復習 |
| ダッシュボード | ハイスコア・伸び率TOP5 | タイムTOP5・到達者数 |
