## 1. システム概要

- **アプリ名称（仮）**：ベクトル分解タイムトライアル（Vector Breakout）
- **コンセプト**：「考えずに直感で選べる」状態を作る、高1物理基礎向け超高速ベクトル成分分解トレーニングツール
- **利用環境**：Webブラウザ（PWA対応想定／スマホ・タブレット・PCレスポンシブ）
- **バックエンド**：Firebase（Cloud Firestore / Realtime Database）

## 2. 目的・学習仮説

- **狙い**：授業冒頭1〜3分の帯活動（ウォームアップ）として継続実施し、ベクトルの成分分解を自動化（パターン反射化）させる
- **教育仮説**：物理の思考（立式・運動予測）におけるワーキングメモリを節約するため、「図の見た目 → 成分（数式）」の変換を認知科学的に自動化させる。数学的な理論の追いつきは後追いで対応する
- **v2での追加仮説**：成分選択の反射を鍛える前段として、「どの角がθと等しいか」を見抜く回路が未定着だと、上位の反射が土台を欠いたまま積み上がる。この判別を独立した最初のステージとして切り出す

## 3. 基本UI・回答方式

| 項目 | 仕様詳細 |
|---|---|
| 画面構成 | 上部：問題となる図（強調表示されたベクトルまたは角）／下部：4択の選択ボタン |
| 出題方式 | 分解されたベクトル図の中で、ターゲットとなるベクトルまたは角を1本（1箇所）強調（赤色・太線等）する |
| 回答方式 | 生徒は強調対象に対応する適切な選択肢を、下部の4択ボタンから選択する |
| テンポ感 | 1問あたり0.5〜1.5秒で回答できる超高速オペラント学習形式 |

## 4. 出題ロジック・グラフィック仕様

### ①-0 角度認識（Level 0・新設）

成分選択の反射に入る前に、「θと合同な角」を見抜く回路を独立して鍛える。

- 出題：分解図の中の複数の角のうち1つを強調し、「θと同じ角か／異なる角か」または「θと同じ角はどれか」を選ばせる
- 目的：錯角・同位角の見落としによる下流の誤答（sin/cos取り違え）を根本から減らす
- Stage 1（成分選択）に進む前提条件として位置づける

### ① 認知パターンのランダム化（「横＝cos」の誤認防止）

常に以下の3パターンのいずれかをランダムに生成・描画する。

- **水平パターン**：水平方向となす角がθ
- **鉛直パターン**：鉛直線となす角がθ
- **斜面パターン**：斜面垂直線となす角がθ（斜面上の重力分解等）

### ② 正解・誤答（ダミー）の判定ロジック

- θの**対辺**（向き合っている辺）を強調 → **sin** 選択肢が正解
- θの**隣辺**（くっついている辺）を強調 → **cos** 選択肢が正解
- **斜辺**（元の力そのもの）を強調 → **F や mg** が正解

### ③ 選択肢の生成ルール（ダミー選択肢）※v2で修正

基本モードの選択肢は「F, Fsinθ, Fcosθ, mg, mgsinθ, mgcosθ」等の**直交成分のみ**で構成する。ダミーもこの枠内に限定し、非直交・比率項（mg/cosθ、mgtanθ 等）は基本モードから排除して発展モードに一本化する。

- **正解例**：mgcosθ
- **ダミー1**：mgsinθ（sin / cos の混同誘発）
- **ダミー2**：Fcosθ（力の名称・記号の混同誘発）
- **ダミー3**：Fsinθ（三角関数と力の名称を同時に取り違えた場合の誘発）

※ tanθ を含む比率項は基本モードの選択肢・ダミーから完全に除外し、6節の発展モードでのみ扱う。

## 5. モード・ステージ構成

### 【基本モード】分解マスター（ウォームアップメイン）

- **Stage 0：角度認識**（新設）… θと合同な角を見抜く。数十秒〜1分程度の短時間ステージ
- **Stage 1：平面分解（基本）** … 水平・鉛直な面での分解
- **Stage 2：斜面分解（実戦）** … 斜面上の重力分解・力の分解
- **Stage 3：ランダム（実力試し）** … 全パターン混合・1分間タイムトライアル

### 【発展モード】tan との使い分け（別モードとして分離）

成分の「長さ」ではなく、2成分間の「比率関係」を問う問題（壁を押す力と垂直抗力など）として完全に独立したステージで出題する。mg/cosθ、mgtanθ 等の非直交項はここでのみ登場する。

## 6. ゲームルール・フィードバック

- **制限時間**：60秒（または90秒／120秒　カスタマイズ可能）
- **スコア算出**：スピードだけでなく、正答率（正確さ）に重きを置く計算式とする
- **即時フィードバック（誤答時）**：誤答した場合、画面上で「対辺＝赤（sin）」「隣辺＝青（cos）」が一瞬ハイライトされ、文字解説なしで残像記憶として正解位置を印象づける

## 7. システム構成・画面遷移

### ① 生徒用画面（/play）

- **ルーム接続**：クラスコード（例：1A）と出席番号／ニックネームを入力
- **ゲームプレイ**：60秒間のタイムトライアル
- **リザルト**：自分のスコア、正答率、前回の自分との比較（成長率）を表示

### ② 教員・投影用ダッシュボード（/dashboard）

プロジェクターや電子黒板にリアルタイム投影する専用画面。

- 現在のリアルタイム参加人数
- クラス全体の平均正答率・平均スコア（リアルタイム集計）
- 本日のハイスコアTOP5（またはスコア伸び率TOP5）
- 誤答率が高かった問題パターン（授業冒頭のピンポイント解説用）

## 8. 非機能要件・開発技術スタック推奨

- **フロントエンド**：Next.js / React, Tailwind CSS
- **数式レンダリング**：KaTeX（高速・軽量描画）
- **データベース・認証**：Firebase Cloud Firestore / Anonymous Auth（匿名認証でログイン不要）
- **画面対応**：
  - スマホ（縦）：上部「図」／下部「2×2の4択ボタン」
  - タブレット・PC（横）：左側「図」／右側「2×2の4択ボタン」

## 実装メモ（v2 の実装で補った点）

| 項目 | 実装 | 設定場所 |
|---|---|---|
| 出題の強調色 | 黄橙の太線＋光彩（誤答時の「赤＝sin」と区別するため） | `src/config/theme.ts` |
| Stage 0 の問い方 | 強調した角の大きさを「θ／90°−θ／90°+θ／180°−θ」から選ぶ。θ と等しい角が約半分。θ=45°±8° は出題しない | `src/config/stages.ts`、`generators/angle.ts` |
| Stage 0 の候補角 | 平面：原点と力の先端の角（錯角など）5種／斜面：物体まわりと斜面頂角の 9 種 | `generators/angle.ts` |
| 力の記号 | 平面パターンは F、斜面パターンは mg | `generators/component.ts` |
| θ の表示 | Stage 2 は底角と物体側（mg と斜面垂直線）の両方に θ、Stage 3 は底角のみ | `showDerivedAngle` |
| ランダム化 | 平面は上下左右反転、斜面は左右反転 | 各 generator |
| スコア式 | 1問 = 100 + 速さボーナス（0.5秒以下で+50、1.5秒以上で0）、合計 × 正答率² | `src/config/game.ts` |
| 誤答時の表示時間 | 0.7 秒（この間は回答不可＝実質のペナルティ） | `src/config/game.ts` |
| 発展モードの題材 | つるしたおもりを水平に引く（T, F）／なめらかな斜面の物体を水平に押す（N, F）。誤答時は力の三角形を表示 | `generators/tan.ts`、`scenes.ts` |
| 前回との比較 | 端末内に同ステージの履歴を保存して比較。ダッシュボードの伸びランキングは送信時の前回スコアとの差 | `lib/storage/local.ts` |
| バックエンド | Cloud Firestore のみ使用（Realtime Database は不使用）。`onSnapshot` でリアルタイム集計 | `lib/firebase/` |
